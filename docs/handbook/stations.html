Stations

Sortable, filterable table of all stations heard on RF and APRS-IS

The Stations page shows every station Graywolf has heard — whether received directly on RF, via a digipeater, or through the APRS-IS iGate — in a table you can sort and filter by any column. Clicking a callsign flies the Live Map to that station and opens its popup.

Find the page in the sidebar under Live Map, or navigate directly to /#/stations.

Table Columns

ColumnDescription
Station The APRS callsign (or object/item name). Click to open the station on the Live Map.
Alias A user-defined display name, e.g. “My Car” or “Dad's Jeep”. Only shown when the Position Log is enabled (aliases are stored alongside position history). Click the pencil icon on any row to edit; leave the field blank to remove an alias.
Last Heard How long ago the most recent packet arrived, with a direction badge: RX (received on RF), IS (APRS-IS iGate), or TX (transmitted by this station).
Icon The station’s APRS symbol icon and its human-readable name.
Distance Straight-line distance from Graywolf’s own GPS position to the station. Shown in km or miles depending on the units preference. Displays “—” when no GPS fix is available.
Bearing True bearing from your station to the remote station, expressed as a compass direction and degrees (e.g. “NNE 22°”). Displays “—” when no GPS fix is available.
Comment The free-form comment field from the station’s most recent packet.
Lat / Lon Decimal-degree coordinates of the station’s most recent position fix.

Sorting

Click any column header to sort by that column. A second click on the same header reverses the direction. A small arrow (↑ / ↓) shows the active sort column and direction. The default sort is Last Heard newest-first.

Filtering

A filter row sits directly under the column headers. Each filter applies independently; multiple active filters are AND’d together.

FilterBehaviour
Station Substring match (case-insensitive). Typing KD shows all callsigns that contain “KD”.
Alias Substring match. A Has alias toggle shows only stations that have a saved alias. The alias filter and toggle are hidden when the Position Log is disabled.
Last Heard A Today only toggle restricts the list to stations heard since midnight local time, regardless of the time-range selector in the toolbar.
Icon A multiselect dropdown listing every APRS symbol currently on the page. Check one or more icons to show only stations with those symbols. Click Clear to remove the icon filter.
Comment Substring match (case-insensitive).

Auto-Refresh and Manual Refresh

Auto-refresh is on by default and polls every 30 seconds. The data updates silently in the background — active filters and sort order are never reset. If you are searching for a specific callsign and that station is heard again, its Last Heard cell updates in place; the filter itself does not change.

Uncheck Auto-refresh in the toolbar to stop polling. The Refresh button fetches fresh data at any time regardless of whether auto-refresh is enabled.

Time Range

The time-range selector in the toolbar (default 1 day) controls how far back Graywolf looks for heard stations. Selecting a longer range may add older entries from the Position Log; selecting a shorter range prunes entries that have aged out. Changing the time range triggers an immediate refresh.

ⓘ

Time ranges beyond a few hours only show historical data when the Position Log is enabled. Without it, stations are held in memory only and a restart clears them.

Pagination

The table shows 50 rows per page by default. Use the per-page selector in the toolbar to switch to 100 or 200. Pagination controls at the bottom of the table let you step through pages. Changing any filter resets to page 1; a refresh that reduces the total count automatically moves you to the last valid page.

Station Aliases

An alias is a personal label you attach to a callsign so it appears in the Alias column whenever that station is heard. Examples: My Car, Dad’s Jeep, Club Digi.

To add or edit an alias, hover over a row and click the pencil icon (✎) in the Alias column. Type your label and press Enter (or click away) to save. Clear the field and save to remove the alias.

⚠

The Alias column and alias editing are only available when the Position Log is enabled. Aliases are stored in the same SQLite database as position history.

Navigating to the Live Map

Click any callsign in the Station column to open the Live Map centered on that station with its popup open. This works even for stations not currently in the map’s active time range — the camera flies to the station’s last known coordinates.
